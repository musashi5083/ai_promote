# Mermaid 矢印エディタ（MVP）

Mermaid 記法で描いた業務フロー図の **矢印を GUI で追加・削除**すると、
**コードにも即反映**される（双方向同期）シンプルなツールです。

業務棚卸し → 図で可視化 → AI 化ポイントの検討、という
AI 推進コンサルの流れを支える最初の一歩として作りました。

## 使い方

`index.html` をブラウザで開くだけ。ビルド・インストール不要です。
（Mermaid 本体は `vendor/` に同梱しているのでオフラインでも動作します）

| モード | 操作 |
|--------|------|
| **選択** | 図を眺める通常モード |
| **＋ 矢印を追加** | 始点ノード → 終点ノード の順にクリックすると `A --> B` が追加されます |
| **－ 矢印を削除** | 削除したい矢印（線）をクリックすると消えます |

- 左ペインの **Mermaid コードを直接編集**すると図に反映されます（コード → 図）。
- 図で矢印を操作すると、コードが書き換わります（図 → コード）。

## 対応範囲（MVP）

- `flowchart` / `graph`（`TD` `LR` など向き指定）
- ノード形状: `[矩形]` `(角丸)` `{ひし形}` `([スタジアム])` `[[サブルーチン]]` `((円))` `{{六角形}}`
- 矢印上のラベル: `A -->|Yes| B`
- 各種コネクタの読み取り: `-->` `---` `-.->` `==>` など

### 制約・既知の割り切り

- GUI で追加する矢印は通常の実線矢印 `-->` になります。
- 図を操作すると、コードは**正規化された形**に書き直されます
  （ノード宣言を上部にまとめる等）。手書きの整形やコメントは保持されません。
- `subgraph` などは表示はできますが GUI 編集の対象外です。

## 構成

```
index.html             単一ファイルの本体（パーサ / シリアライザ / GUI）
vendor/mermaid.min.js  同梱した Mermaid v9.4.3（描画エンジン）
```

## 今後の拡張候補

- 矢印の**線種変更**（実線⇄点線、太線）・**ラベル編集**・**向きの反転**
- ノードの追加・リネーム・形状変更
- 整形やコメントを壊さない差分編集（現状は正規化書き換え）
- 業務フローからの AI 化ポイント自動提案
