# Mermaid フロー エディタ

Mermaid記法の業務フロー図を、**GUIで直接操作**するとコードにも即反映される
（双方向同期）シンプルなエディタです。

業務棚卸し → 図で可視化 → AI化ポイントの検討、という
AI推進コンサルの流れを支えるツールとして育てています。

## 使い方

`index.html` をブラウザで開くだけ。ビルド・インストール不要です。
（Mermaid本体は `vendor/` に同梱しているのでオフラインでも動作します）

### 操作（モードレス直接操作）

| 操作 | 結果 |
|------|------|
| **クリック** | ノード／矢印を選択 |
| **ノードからドラッグ** | 矢印を引く。**空白へ離すと新しいノードを生成**して連結 |
| **ダブルクリック**（ノード／矢印） | その場で文字（ラベル）を編集 |
| **ダブルクリック**（空白） | 新しいノードを追加 |
| **右クリック** | 文脈メニュー（ラベル編集／形状・線種変更／向き反転／削除） |
| **ノード選択中のツールバー** | 形状変更（矩形・判断◇・角丸・開始終了）／削除 |
| **矢印選択中のツールバー** | 線種変更（実線→・点線⇢・太線⇛）／向き反転⇄／削除 |
| **Delete / Backspace** | 選択中のノード・矢印を削除 |
| **Ctrl+Z / Ctrl+Y** | 元に戻す／やり直し |

- 上部ツールバー: **＋ノード追加**、**元に戻す/やり直し**、**図の向き**（TD/LR/BT/RL）、**コードをコピー**。
- 左のMermaidコードはそのままキーボードでもOK（コード→図の同期）。
- 図を操作するとコード側にも反映（図→コード）。

## 対応範囲

- ノードの**追加・削除・リネーム**、**形状変更**（矩形/判断/角丸/開始終了/その他Mermaid形状の読み取り）
- 矢印の**追加・削除・ラベル編集・線種変更（実線/点線/太線）・向き反転**
- 図全体の**向き**（TD/LR/BT/RL）
- **Undo/Redo**、コード/図の**双方向同期**

### 制約・既知の割り切り

- Mermaidは**自動レイアウト**のため、ノードを好きな座標へ自由配置することはできません
  （配置はエンジンが自動計算。GUIで編集するのは「構造」＝ノード・矢印・ラベル・形状・向き）。
- 図を操作すると、コードは**正規化された形**に書き直されます
  （ノード宣言を上部にまとめる等）。手書きの整形やコメントは保持されません。
- `subgraph`（グループ化）は表示のみ対応（GUI編集は今後）。

## 構成

```
index.html             単一ファイルの本体（パーサ / シリアライザ / GUI）
vendor/mermaid.min.js  同梱した Mermaid v9.4.3（描画エンジン）
```
