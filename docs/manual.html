🗺️ Mermaid フロー エディタ ― はじめての方向けマニュアル

マウスでブロックと矢印を並べるだけで、業務フロー図が作れるツールです。インストール不要・ブラウザだけで動きます。

このマニュアルの前提
  • ツール本体（mermaid-flow-editor.html）を SharePoint からダウンロードして使います。
  • ダウンロードした HTML を ブラウザで開いて使います（インストール不要）。
  • 作った図は .mmd ファイルとして ローカル（Box Drive などの同期フォルダ）に保存します。

1準備：ダウンロードして開く

  1. SharePoint の共有場所を開き、mermaid-flow-editor.html を探します。
  2. そのファイルを 自分のPCにダウンロードします。保存先は、ふだん使う Box Drive の同期フォルダやデスクトップが分かりやすいです。
  3. ダウンロードした mermaid-flow-editor.html を ダブルクリックして開きます。
    （うまく開かない時は、ファイルを Chrome か Edge のウィンドウにドラッグ＆ドロップしてください）
✅ ブラウザは Chrome か Edge を推奨 保存ダイアログや「上書き保存」がきちんと使えます。Firefox / Safari でも図は作れますが、保存は「ダウンロード」動作になります（後述）。
ℹ️ インターネットに接続していなくても動きます このツールは1枚のHTMLで完結しており、外部との通信は一切しません。安心して社内でお使いいただけます。

2画面の見方

画面は左右に分かれています。

左：Mermaid コード図の「設計図」にあたるテキストです。基本は触らなくてOK。図を編集すると自動で書き換わります。分かる人は直接編集も可能です。
右：プレビュー実際のフロー図。ここをマウスで操作してブロックや矢印を作ります。

上部のツールバーに、＋ ノード ↶ ↷（元に戻す/やり直し） 向き 🧹 整理 💾 上書き保存 📝 名前を付けて保存 📂 読み込み 📋 コードをコピー があります。

3基本操作（ブロックと矢印）

ブロックを追加する

  • ブロックの下の「＋」：ブロックを1回クリックすると下に ＋ が出ます。押すと下に次の工程が矢印付きで追加され、そのまま名前を入力できます。（いちばん手軽）
  • 何もない所をダブルクリック：単独のブロックを追加します。
  • ツールバーの「＋ ノード」：ブロックを1つ追加します。

矢印でつなぐ

  • ブロックの上で マウスを押したまま、つなぎたい相手のブロックまでドラッグして離すと、矢印が引けます。ドラッグ中は青い点線の矢印が伸びて向きが分かります。
  • ブロックから 何もない所へドラッグして離すと、新しいブロックを矢印付きで作れます。続けて名前を入力できます。

分岐（条件で枝分かれ）

  • ブロックを選び、形を ◇（判断）に変えます（下記「形を変える」参照）。
  • ◇からドラッグして矢印を引くと分岐になり、続けて 条件（例：はい / いいえ）を入力できます。

間に工程を差し込む

  • 矢印を1回クリックして選び、出てくるメニューの ＋工程 を押すと、その矢印の途中に新しいブロックが入ります。

形を変える・複製・削除

  • ブロックを選ぶと小さなメニューが出ます：▭ 四角 / ◇ 判断 / ▢ 角丸 / ⬭ 開始終了 に形を変更、⧉ 複製、🗑 削除。
  • 矢印を選ぶと：線の種類（→ 実線 / ⇢ 点線 / ⇛ 太線）、⇄ 向き反転、🗑 削除。
  • 右クリックでもメニューが出ます。

全体の向き・整理

  • ツールバーの 「向き」で、上→下(TD)・左→右(LR)などに切り替えられます。
  • 🧹 整理を押すと、配置を計算し直してきれいに並べ直します。

4文字を書く・太字・改行

  1. ブロックを ダブルクリックすると、大きな入力窓が開きます。
  2. 文字を入力します。日本語入力（IME）もそのまま使えます。
  3. 途中で改行したいときは Shift+Enter、または入力窓の下の ↵ 改行 ボタン。
  4. 強調したい所は、文字を選んで Ctrl+B、または B 太字 ボタン。
  5. 書き終えたら Enter で確定（Esc で取り消し）。

※ 太字は編集中は <b>…</b> というタグの形で見えますが、確定するとブロック内で太字になります。

5保存と読み込み（重要）

作った図は .mmd という小さなテキストファイルで保存します。これが図の本体です（ツールのHTMLは「道具」で、図そのものではありません）。

はじめて保存するとき

  1. ツールバーの 📝 名前を付けて保存 を押します。
  2. 保存ダイアログで Box Drive の同期フォルダ（例：Box\チーム名\フロー図\）を選びます。
  3. 分かりやすい名前を付けて保存します（例：受注業務フロー.mmd）。
✅ Box を使っている場合 Box Drive の同期フォルダに保存すれば、自動でクラウドに上がり、チームにも共有されます。PC上のふつうのフォルダと同じ感覚で保存すればOKです。

2回目以降（上書き保存）

  • Ctrl+S、または 💾 上書き保存 で、今のファイルにダイアログなしで上書きされます。

前に作った図を開く

  • 📂 読み込み を押して .mmd ファイルを選びます。開いたファイルは記憶されるので、以後 Ctrl+S で同じファイルに上書きできます。
⚠️ 保存ダイアログが出ない場合 お使いのブラウザや会社の設定によっては、ダイアログが出ず 「ダウンロードフォルダ」に保存（ダウンロード）されることがあります。その場合は、ダウンロードされた .mmd を Box Drive のフォルダに移動してください。
ダイアログと「上書き保存」をきちんと使うには Chrome または Edge で、ダウンロードしたHTMLを開くのが確実です。

他の人に見せたいとき

  • 📋 コードをコピーで Mermaid コードをコピーし、Mermaid対応のメモ（社内Wiki等）に貼ると図として表示できます。
  • または .mmd ファイルそのものを共有し、相手はこのツールの 📂 読み込みで開けます。

7困ったとき（Q&A）

Q. ダブルクリックしても図が出ない／うまく開かない

A. ファイルを Chrome か Edge のウィンドウにドラッグ＆ドロップしてみてください。ブラウザの「規定のアプリ」設定によっては別ソフトで開こうとすることがあります。

Q. 「名前を付けて保存」でダイアログが出ない

A. ブラウザや社内設定の都合で、ダウンロード動作になっている状態です。ダウンロードされた .mmd を Box フォルダへ移動すればOK。ダイアログを使いたい場合は Chrome/Edge でローカルのHTMLを開いてください。

Q. 入力中に文字がおかしくなる

A. 最新版では日本語入力（変換確定のEnter）に対応済みです。もし古いファイルを使っている場合は、SharePoint から 最新の mermaid-flow-editor.html を再ダウンロードしてください。

Q.「⚠ 図を描画できません」と出た

A. 左のコードを直接編集したときに、記法が崩れると出ます。元に戻す（Ctrl+Z）で戻すか、直前の編集を見直してください。マウス操作だけで作っていれば基本的に出ません。

Q. 保存した図はどこにある？

A. 保存時に選んだフォルダ（推奨：Box Drive の同期フォルダ）です。ダイアログが出ない環境では PCの「ダウンロード」フォルダに入ります。

Q. Mermaid コードって何？触っても大丈夫？

A. 図を表す短いテキストです。基本は触らなくて大丈夫。分かる人は直接編集でき、内容はすぐ右の図に反映されます。

わからないことがあれば、共有元の担当者までお気軽に。 🗺️
